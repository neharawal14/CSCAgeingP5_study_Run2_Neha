## Pressure information is taken from the cmsonlineweb.cern.ch website

Pressure values obtained from -
https://cmsonline.cern.ch/webcenter/portal/cmsonline/pages_services/sensorsforcms

In 2016 - there were only USC values.  The values could be obtained as average over 1minute. These values are in integer 
In 2017 : Only USC pressure is active during whole time  - only available in integer
In 2018 : should use MiliQan pressure values with better least count compared to USC

Run the program - pressure_program.py over this pressure csv files, and you will obtain final pressure values to put in the analysis
